# mod3project

## Project overview

Finplan app allows user to track their spending and have a clear analysis on their spending habbits.

## Languages used

This project primarily uses JavaScript (React). Tailwind CSS is used for styling and standard HTML elements are included inside the .jsx files.

## Installation

This project requires no special installation to view the built app — it can be run locally during development or deployed to a static host. For local development you will need Node.js and npm to run the dev server.

## How to run

1. Clone the repository:

	`git clone https://github.com/1Enock/mod3project`

2. Open the project folder.

3. Navigate into the project directory and install dependencies:

	`cd my-app`
	`npm install`

4. Start the dev server:

	`npm run dev`

5. Open the localhost link shown in the terminal to view the web application (usually http://localhost:5173).

## Purpose of the project

The project aims to simplify voting workflows by allowing users to create polls, vote, and see live vote percentages without manual tallying.

## Deployment & CI/CD

This project uses **GitHub Actions** for automated testing, building, and deployment with **Semantic Versioning**.
